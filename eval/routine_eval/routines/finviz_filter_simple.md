# Workflow: Screen for small-cap value stocks with momentum on Finviz

## Step 1: Open the Finviz screener

Open `http://localhost:16605/finviz/` in the current tab.

## Step 2: Set Market Cap to "+Small (over $300mln)"
**Keywords:** fs_cap

Select the option `smallover` ("+Small (over $300mln)") from the Market Cap
dropdown on the Descriptive filter tab.

## Step 3: Set Dividend Yield to "Over 3%"
**Keywords:** fs_fa_div

Select the option `o3` ("Over 3%") from the Dividend Yield dropdown.

## Step 4: Set Relative Volume to "Over 1"
**Keywords:** fs_sh_relvol

Select the option `o1` ("Over 1") from the Relative Volume dropdown.

## Step 5: Switch to the Fundamental filter tab
**Keywords:** fundamental

Click the "Fundamental" tab in the filter tab bar to reveal the fundamental
filter dropdowns.

## Step 6: Set P/E to "Under 20"
**Keywords:** fs_fa_pe

Select the option `u20` ("Under 20") from the P/E dropdown.

## Step 7: Set P/B to "Under 2"
**Keywords:** fs_fa_pb

Select the option `u2` ("Under 2") from the P/B dropdown.

## Step 8: Switch to Performance view
**Keywords:** view-tab

Click the "Performance" view tab in the results area to switch the table to
the performance view.

## Step 9: Sort by Perf Month descending
**Keywords:** perf4w

Click the "Perf Month" column header to sort the results by monthly
performance in descending order.

## Step 10: Open the top 3 stocks

Click on each of the top 3 stock tickers in the sorted results table to open
their detail pages. These are whichever stocks appear at the top after
sorting — not specific tickers.
