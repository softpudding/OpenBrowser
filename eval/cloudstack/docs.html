Step 1: Create an Account

Before you can use CloudStack services, you need to create an account. Click Sign Up to get started. New users receive ¥1000 in credits to try our services.

💡 Note: You'll need to complete real-name verification to use all CloudStack services. This is required by Chinese regulations.

Step 2: Configure Billing

Add a payment method to your account. We support:

  • Credit/Debit Cards (Visa, MasterCard, UnionPay)
  • Alipay
  • WeChat Pay
  • Bank Transfer (for enterprise accounts)

Step 3: Launch Your First Instance

Go to the Console and follow these steps:

  1. Click "Create Instance" in the ECS console
  2. Choose your region (e.g., Hangzhou, Beijing, Shanghai)
  3. Select an instance type (e.g., ecs.g6.large for general purpose)
  4. Choose an operating system image (Ubuntu, CentOS, Windows)
  5. Configure network settings and security groups
  6. Review and confirm your order
# Example: Connect to your ECS instance via SSH
ssh root@your-instance-ip

# Check instance status
uptime
free -h
df -h
⚠️ Security Warning: Always configure security groups to restrict access to your instances. Only open the ports you need (e.g., 22 for SSH, 80/443 for web servers).

API Integration

CloudStack provides RESTful APIs for programmatic access to all services. Here's a simple example:

Describe Instances

Get information about your ECS instances.

GET/api/v1/ecs/instances

Create Instance

Launch a new ECS instance.

POST/api/v1/ecs/instances

Start Instance

Start a stopped instance.

POST/api/v1/ecs/instances/{instanceId}/start

Delete Instance

Terminate an instance.

DELETE/api/v1/ecs/instances/{instanceId}

SDK Support

We provide official SDKs for popular programming languages:

  • Python SDK - pip install cloudstack-sdk
  • Java SDK - Maven/Gradle dependency available
  • Go SDK - go get github.com/cloudstack/sdk-go
  • Node.js SDK - npm install @cloudstack/sdk
  • .NET SDK - NuGet package available
